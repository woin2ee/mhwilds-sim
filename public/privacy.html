개인정보 처리방침

와일즈 스킬 시뮬레이터 (비공식) · 시행일 2026년 10월 30일

와일즈 스킬 시뮬레이터(https://woin2ee.github.io/mhwilds-sim/)는 몬스터 헌터 와일즈의 방어구 세팅을 계산하는 비공식 팬메이드 도구입니다. 별도의 서버 없이 브라우저 안에서만 동작하며, 운영자는 이용자의 정보를 수집하거나 보관하지 않습니다.

브라우저에 저장하는 정보

  • 내 세팅, 내 호석, 검색 조건, 화면 설정(테마 등)은 이용 중인 브라우저의 저장소(localStorage)에만 저장됩니다. 운영자에게 전송되지 않으며, 브라우저 데이터를 지우면 함께 지워집니다.
  • ‘사진으로 호석 추가’에 넣은 스크린샷은 브라우저 안에서만 읽고 어디에도 보내지 않습니다.
  • 방문 분석 도구나 광고, 쿠키를 쓰지 않습니다.

Google 드라이브 동기화 (선택)

백업 탭에서 Google 계정을 연결하면 여러 기기의 데이터를 맞출 수 있습니다. 연결하지 않으면 아래 내용은 해당되지 않습니다.

  • 요청하는 권한: https://www.googleapis.com/auth/drive.appdata 하나뿐입니다. Google 드라이브에서 이 사이트만 쓰는 숨김 공간(앱 데이터 폴더)의 파일을 만들고 읽고 고치는 권한이며, 드라이브의 다른 파일은 보거나 바꿀 수 없습니다.
  • 저장하는 데이터: 내 세팅, 내 호석, 저장한 검색 조건, 지금 검색 조건, 수동 세팅을 담은 파일 하나 (mhwilds-sim-sync.json)를 이용자 본인의 드라이브 앱 데이터 폴더에 저장합니다.
  • 계정 정보: 연결한 계정을 화면에 보여 주고 같은 계정인지 확인하려고, Google 드라이브가 알려 주는 이름·이메일 주소·계정 식별자를 이 브라우저에만 저장합니다.
  • 접근 토큰: 로그인으로 받은 접근 토큰(1시간 동안 유효)은 페이지를 새로 고쳐도 다시 로그인하지 않도록 이 브라우저에 저장했다가 동기화에만 씁니다.
  • 전송 경로: 데이터는 이용자의 브라우저와 Google 사이에서만 오가며, 운영자의 서버를 거치거나 운영자에게 전달되지 않습니다.
  • Google 사용자 데이터를 동기화 외의 목적(광고, 분석 등)에 쓰거나 다른 곳에 제공하지 않습니다. 이 사이트가 Google API 에서 받은 정보를 쓰고 옮기는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

동기화 데이터 지우기와 권한 해제

  • 사이트의 백업 탭 → Google 드라이브 동기화 → ‘연결 끊기’에서 ‘드라이브에 저장된 동기화 데이터도 지우기’를 고르면 드라이브의 동기화 파일을 지웁니다.
  • Google 드라이브 웹의 설정 → 앱 관리에서 이 앱의 ‘숨겨진 앱 데이터 삭제’로도 지울 수 있습니다.
  • 이 사이트에 준 권한은 Google 계정의 타사 앱 및 서비스에서 해제할 수 있습니다.

외부 서비스

  • 사이트는 GitHub Pages 에서 제공되며, GitHub 이 일반적인 접속 기록을 남길 수 있습니다.
  • 글꼴(Pretendard)은 jsDelivr CDN 에서 불러옵니다.
  • Google 로그인 스크립트(accounts.google.com)는 백업 탭을 열었거나 드라이브 동기화를 연결했을 때만 불러옵니다.
